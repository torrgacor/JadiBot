DAFTAR BAHASA YANG DIDUKUNG google-translate-api-x
Untuk digunakan pada konfigurasi FROM dan TO.

Catatan penting:
- FROM boleh memakai "auto" untuk deteksi otomatis.
- TO harus memakai kode bahasa tujuan, contoh: "ja", "en", "id".
- Untuk text-to-audio/TTS, tidak semua bahasa translate punya suara.
- Package google-translate-api-x menyediakan helper languages, isSupported, dan getCode untuk cek dukungan bahasa secara langsung dari kode.
- Google Translate dan package dapat update sewaktu-waktu, jadi daftar paling akurat tetap dicek dari package.

CONTOH KONFIGURASI

Translate Indonesia ke Jepang:
const MODE = "text-to-text";
const FROM = "id";
const TO = "ja";

Teks Indonesia jadi audio Jepang:
const MODE = "text-to-audio";
const FROM = "id";
const TO = "ja";
const AUTO_TRANSLATE_BEFORE_TTS = true;

Teks Jepang langsung jadi audio:
const MODE = "text-to-audio";
const FROM = "ja";
const TO = "ja";
const AUTO_TRANSLATE_BEFORE_TTS = false;

import { languages, isSupported, getCode } from "google-translate-api-x";

console.log(languages);
